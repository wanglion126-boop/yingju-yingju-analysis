# 04：提炼条件性案例

请按 AGENTS.md，从 T001 中用户已明确接受且允许沉淀的指定结论提炼一个条件性案例。先检查复核授权和适用条件；授权或结论版本不明确时列出待确认项。**先生成案例草稿**，仅保存到 results/T001/ 下未占用的 Markdown 文件。写清材料性质、初始条件、事件过程、候选行动、成立条件、反例、不适用范围和验证状态，保留事实与解释的区别。T001 是虚构演示，不能写成真实记录或用户已验证的案例。**未经用户确认草稿、目标文件及验证状态，不改写 context 或正式案例（包括 cases/INDEX.md）**；用户接受分析也不自动授权修改规则。
