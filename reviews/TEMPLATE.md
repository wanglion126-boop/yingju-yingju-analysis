# 用户复核模板

此文件是空白模板，不代表已有复核结论。复制填写；保存为新反馈文件前应有用户授权，不覆盖本模板。

- 对应任务：
- 对应结果文件与版本：
- 反馈人中性代号（可不填）：
- 输入是否准确（准确 / 有误 / 未确认）：
- 输入更正与依据：
- 对象是否被误读（角色、类型、实例、所属侧、引用）：
- 时间是否被误读（发生时间、获知时间、区间、未知）：
- 接受哪些结论及其条件：
- 否定哪些结论及理由：
- 仍需确认的问题：
- 新证据（内容、证据标识、发生时间、当时获知时间；未知请明示）：
- 是否允许从指定结论生成案例草稿（是 / 否 / 未决定）：
- 是否确认草稿进入正式案例（须写草稿版本、目标编号与验证状态；否则未授权）：
- 是否授权修改输入或规则（具体文件与改动；留空不视为授权）：

接受单条结论不等于接受全部结论；允许生成草稿不等于允许写入正式案例，也不等于允许修改 context。虚构演示不能因复核被称为已经真实记录验证。
